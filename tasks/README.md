# Team Tasks

SafeRoad의 명확한 작업 단위와 FitWise의 로드맵/완료 기준 방식을 결합하되, 5명이 빠르게 병렬 작업할 수 있도록 단순화했습니다.

## 작업 규칙

1. 모든 작업은 이슈 하나와 담당자 한 명을 가집니다.
2. PR에는 화면 캡처 또는 테스트 결과를 첨부합니다.
3. 데이터 계약 변경은 UI 작업보다 먼저 리뷰합니다.
4. `main`에는 직접 push하지 않고 최소 1명 리뷰 후 병합합니다.
5. 신청서, 연락처, 실제 위치/음성, API 키는 업로드하지 않습니다.

## 브랜치 예시

```text
feat/hmi-shell
feat/mock-scenario-runner
feat/drive-mood
feat/car-relay
docs/demo-script
fix/panel-overflow
```

현재 작업은 [CURRENT.md](CURRENT.md), 완료 판단은 [DEFINITION_OF_DONE.md](DEFINITION_OF_DONE.md)를 기준으로 합니다.
