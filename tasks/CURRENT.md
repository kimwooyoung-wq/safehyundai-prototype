# Current Sprint — Prototype Demo

## Sprint Goal

현재 Figma의 지도 중심 HMI를 기준으로, 외부 네트워크 없이 3개의 시나리오를 재현할 수 있는 코드 데모를 만듭니다.

| 우선순위 | 담당 역할 | 작업 | 완료 결과 |
|---|---|---|---|
| P0 | Planning | 요구사항 고정·시연 대본·저장소 통합 | README와 90초 내레이션 승인 |
| P0 | App | React HMI 기반·시나리오 러너·배포 | URL에서 데모 실행 가능 |
| P0 | Data | 모의 차량 데이터·추천/분류 규칙 | 3개 fixture와 단위 테스트 |
| P0 | Design | Figma 컴포넌트·지도/사진/앨범 에셋 | 상태별 패널과 export asset |
| P0 | QA | 시나리오 QA·영상·발표 | 체크리스트 통과와 90초 영상 |

## 통합 순서

1. Data 역할이 `VehicleSnapshot`, `DriveEvent` 샘플을 확정합니다.
2. App 역할이 시나리오 러너와 HMI 프레임을 연결합니다.
3. Design 역할이 같은 컴포넌트 이름으로 에셋을 전달합니다.
4. Planning 역할이 문구와 시연 순서를 확정합니다.
5. QA 역할이 새 브라우저/오프라인/해상도별로 검증합니다.

## 이번 스프린트에서 하지 않는 것

- 실제 차량 제어
- 검증되지 않은 Pleos 데이터 접근
- 모델 학습 파이프라인
- 전체 음원 파일 배포
- 자동 카메라 촬영
- 다중 사용자 운영 서버
