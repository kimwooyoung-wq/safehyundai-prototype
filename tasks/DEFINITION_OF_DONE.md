# Definition of Done

## 공통

- 요구사항 또는 이슈 번호가 PR에 연결되어 있다.
- 로컬 실행 방법이 README에 반영되어 있다.
- 타입 오류와 lint 오류가 없다.
- 변경된 핵심 동작에 테스트가 있다.
- 비밀키, 개인정보, 원본 신청서가 포함되지 않았다.

## UI 작업

- Figma 컴포넌트와 코드 컴포넌트 이름이 대응된다.
- 16:9 기준에서 잘림이 없다.
- 작은 텍스트에만 정보를 의존하지 않는다.
- 운전 중 필요한 버튼은 큰 터치 영역을 갖는다.
- 로딩, 데이터 없음, 연결 끊김 상태가 있다.

## 데이터/AI 작업

- 입력과 출력 타입이 문서화되어 있다.
- 추천 또는 분류 근거를 재현할 수 있다.
- 같은 fixture에서 항상 같은 결과가 나온다.
- “진단”이나 “사고 예측”으로 과장하지 않는다.

## 시연 준비

- 오프라인에서 실행된다.
- 초기화 버튼으로 동일한 시작 상태를 만든다.
- 시나리오 A, B, C가 각각 끝까지 진행된다.
- 실제 연동과 모의 데이터가 화면/문서에서 구분된다.
- 시연 영상과 Figma/GitHub 링크가 제출 전 열리는지 확인한다.
