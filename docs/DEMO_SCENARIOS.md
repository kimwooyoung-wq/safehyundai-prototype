# Demo Scenarios

## 시연 원칙

- 전체 시연은 3분을 넘기지 않습니다.
- 각 시나리오는 `초기화` 버튼으로 같은 상태에서 시작합니다.
- 발표자는 동승자 또는 정차 상태에서 조작합니다.
- 차량 값은 모의 데이터임을 시작/종료 화면에 표기합니다.

## 시나리오 A — 뚝섬 여행 경험

1. 한양대역 부근에서 뚝섬역으로 이동하는 지도 화면을 시작합니다.
2. 45분 이상 주행과 여행 목적지를 근거로 `장거리 여행 모드`가 선택됩니다.
3. 우측 패널에 앨범 이미지, 실제 곡명, 추천 이유가 표시됩니다.
4. 중랑천 구간에서 `풍경 기록 추천` 핀이 나타납니다.
5. 버튼을 누르면 뚝섬 노을 사진, 장소, 재생 중 음악이 하나의 기록으로 저장됩니다.
6. 주행 종료 후 여행 타임라인 카드가 생성됩니다.

평가 포인트: 운전 중 조작 감소, 차량 데이터와 콘텐츠 연결, 추억 자동 정리.

## 시나리오 B — 가족 차량 인수인계

1. 이전 운전자가 “운전석 앞바퀴 공기압이 낮았어요”를 남깁니다.
2. 시스템은 대본을 `타이어/주의`로 분류하고 모의 TPMS 값과 결합합니다.
3. 다음 운전자가 탑승하면 우측 패널에 인수인계가 먼저 표시됩니다.
4. `확인`을 누르면 읽음 상태가 저장됩니다.
5. 정비 후 `해결` 처리하면 반복 문제의 이력을 확인할 수 있습니다.

평가 포인트: 누락 방지, 차량 신호와 사람 설명의 결합, 공유차량 확장성.

## 시나리오 C — 장거리 주행 안전 요약

1. 주행 시간이 70분을 넘고 급감속 횟수가 평소보다 증가합니다.
2. 운전 중에는 한 번만 휴식 권고가 표시됩니다.
3. 음악/풍경 알림은 잠시 낮은 우선순위로 전환됩니다.
4. 주행 종료 후 평소 대비 급감속, 주행 시간, 휴식 여부를 요약합니다.

평가 포인트: 방해 최소화, 설명 가능한 판단 근거, 과도한 안전 주장 방지.

## 90초 영상 구성

| 시간 | 화면 | 내레이션 요지 |
|---:|---|---|
| 0~10초 | 지도와 차량 상태 | 차량이 주행 맥락을 읽기 시작합니다. |
| 10~25초 | Drive Mood | 장거리·목적지·선호를 바탕으로 음악을 제안합니다. |
| 25~45초 | 풍경 기록 | 위치와 음악을 함께 남겨 여행 타임라인을 만듭니다. |
| 45~65초 | Car Relay | 사람의 음성과 차량 상태를 다음 운전자에게 전달합니다. |
| 65~80초 | Guardian 요약 | 운전 중 방해는 줄이고 종료 후 패턴을 보여줍니다. |
| 80~90초 | 확장 구조 | 모의 어댑터를 Pleos 연동으로 교체할 수 있습니다. |
