# Pleos / 실제 차량 연동 확인표

“가능할 것”과 “공식적으로 확인된 것”을 구분하기 위한 체크리스트입니다. 공식 개발자 문서, 계정 권한, 테스트 차량 또는 시뮬레이터에서 검증되기 전에는 `확정`으로 표시하지 않습니다.

| 데이터/기능 | 프로토타입 대체 | 실제 연동 시 확인할 항목 | 미확인 시 처리 |
|---|---|---|---|
| 속도·기어·주행 상태 | 시간축 mock telemetry | 신호 이름, 갱신 주기, 읽기 권한 | 시뮬레이션 표기 |
| 배터리/연료/주행 가능 거리 | 고정 값과 이벤트 | EV/ICE 차이, 단위 | 선택적 필드 처리 |
| 타이어 공기압 | 4륜 샘플 값 | TPMS 접근, 임계치 책임 | 경고 코드 또는 대본 사용 |
| 경고등 | 내부 표준 WarningCode | 제조사 코드 매핑, 아이콘 사용 조건 | 임의 진단 금지 |
| 위치·경로 | 로컬 벡터 경로 | GPS/목적지/ETA 권한 | 로컬 시나리오 유지 |
| 미디어 재생 | 로컬 트랙 메타데이터 | 재생 앱 제어, 저작권, 포커스 | UI만 시연, 음원 배포 금지 |
| 음성 입력 | 준비된 대본/녹음 | 마이크 권한, STT 제공 여부 | 대본 선택 fallback |
| 사용자 프로필 | 로컬 데모 프로필 | 계정 식별자, 공유차량 분리 | 익명 세션 ID 사용 |

## 검증 절차

1. 공식 문서에서 읽기 가능한 데이터 목록을 확보합니다.
2. 단위, nullable 여부, 갱신 주기, 권한을 기록합니다.
3. `VehicleDataPort` 내부 모델과 매핑합니다.
4. 시뮬레이터에서 정상/오류/연결 끊김을 재현합니다.
5. 같은 UI 테스트를 Mock과 Pleos 어댑터에 반복합니다.
6. 검증된 항목만 README 상태를 `INTEGRATED`로 변경합니다.

## Go/No-Go 기준

- **Go**: 공식 문서가 있고 허용된 읽기 API이며 시뮬레이터에서 재현됨
- **Conditional**: 문서는 있으나 계정/차종/권한에 따라 달라짐
- **No-Go**: 비공개 신호, 안전상 제한된 제어, 라이선스가 불분명한 데이터
